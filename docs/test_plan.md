# Phase 4: 通信キャプチャ用テスト計画

HCI Snoop Logは全テストの通信が1つのログファイルに連続して記録されます。
後でWiresharkで見たときに「どのパケットがどのテストか」を区別できるよう、
**印刷した順番と大まかな時刻**をこの表に記録してください（秒単位まで正確でなくてOK、前後の見分けがつけば十分です）。

## 既知の注意事項

プリンターの給紙モーターに不具合があり、印字動作音はしても紙が送られない症状が確認されています（ハードウェア側の問題と推測）。
**この作業では紙に実際に印字されるかどうかは問いません。** Bluetooth通信さえ発生していれば、HCI Snoop Logに記録が残り解析に使えます。
気にせずこのままテストを進めてください。

## 実施ルール

- 1回の印刷で変更する要素は1つだけにする
- 印刷ごとに少し間隔をあける（数秒）と、後でログを見分けやすくなります
- 順番は変えないでください（下の表の順で実施）

## 画像テスト用データについて

I01〜I06は、アプリ内に画像作成・選択機能があればそれを使ってください。
なければ、PC等で単純な画像（例: 384x384pxの全白/1ドット黒/横線/縦線/四角）を作成し、
スマートフォンに転送してアプリから選択・印刷してください。凝ったものである必要はありません。

## 画像テスト（I01〜I06）について：保留中

解析用端末（Android 7.0）の性能不足により、アプリの「画像」メニューが開けずフリーズしてしまうため、
現時点ではI01〜I06のキャプチャを取得できません。まずは文字テスト（T01〜T08, Q01, Q03）を優先して進め、
画像キャプチャは端末の目処が立ち次第、別途対応します。
