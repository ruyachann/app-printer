# captures/ ディレクトリについて

Wiresharkで抽出した「プリンター方向のWrite通信データ」を保存する場所です（手順書 Phase 8）。

## ディレクトリ構成と対応するテスト内容

| ディレクトリ | 内容 |
|---|---|
| `text_A/` | 文字「A」印刷時の通信データ |
| `text_B/` | 文字「B」印刷時の通信データ |
| `text_AB/` | 文字「AB」印刷時の通信データ |
| `qr_text/` | 「ABC123」を**文字として**印刷した通信データ |
| `qr_code/` | 「ABC123」を**QRコードとして**印刷した通信データ |
| `image_dot/` | 黒1ドット画像印刷時の通信データ |
| `image_line/` | 黒い横線/縦線画像印刷時の通信データ |
| `image_square/` | 黒い四角画像印刷時の通信データ |

## 保存するファイル形式（推奨）

各ディレクトリに以下を保存してください。

- `raw.hex` または `raw.bin`: Write通信の生データ（16進数テキスト、またはバイナリ）
- `note.md`: パケット数、パケットサイズ、気づいた点などのメモ

## 命名例

```text
captures/text_A/raw.hex
captures/text_A/note.md
```

これらのデータをもとに `docs/protocol_spec.md` を埋めていきます。
