# rfcomm_jobs/ について

`btsnoop_hci_2026-08-26.log` から `tools/btsnoop_parser/extract_jobs.py` で切り出した、
印刷ジョブ単位の生バイナリです（RFCOMM CID 0x0051, DLCI=2 のUIHペイロードを結合し、
ヘッダーマジック `1D 47 59` で分割したもの）。

## 注意：テスト項目との対応は未確定

このキャプチャセッション中、ユーザーはプリンターの給紙不良のトラブルシューティング
（用紙カバーの開閉、用紙の向き確認など）のため印刷ボタンを複数回押した可能性があり、
`docs/test_plan.md` に記載の10項目（T01〜T08, Q01, Q03）に対して **18個のジョブ**が
検出されています。そのため、どのジョブがどのテスト文字列に対応するかは、
バイト列のパターン分析（文字数・データ長の違いなど）で今後突き合わせる必要があります。

## 次のステップ

- 各ジョブのバイト列を可視化（1bitビットマップとして描画）し、実際にどの文字が印字されているか判定する
- ジョブごとのデータ長の違いと、印字した文字列の長さ・複雑さとの相関を確認する
- ヘッダー `1D 47 59 04 30 00 17 00` の各バイトの意味（コマンド種別・幅・高さ・モード等）を特定する
- フッター `1B 4A 50 ...` の意味（行送り量・チェックサム等）を特定する
